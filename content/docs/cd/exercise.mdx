## Notre premier déploiement fait main


Nous avons une image Docker `react-nginx` qui fonctionne parfaitement sur notre machine locale.    
C'est bien, mais ça ne sert à rien si personne ne peut la voir.

Votre mission : Déployer cette application sur Render

### Les Outils Imposés
- Docker Hub: comme registre d'images
- Render: comme plateforme d'hébergement
- Github: pour héberger votre code bien sûr

### Objectifs à Atteindre

Vous avez réussi quand vous avez complété les 3 objectifs suivants :

- Image: Votre image `react-nginx` doit être publiée sur votre compte Docker Hub et accessible publiquement.
- Application en ligne : Un service web doit être configuré et démarré sur Render. Ce service doit **exécuter votre image Docker Hub** et rendre l'application accessible via une URL publique.
- Clé d'Automatisation : Vous devez avoir trouvé et copié l'URL du "Deploy Hook" de votre service Render. Gardez-la précieusement, elle sera le "secret" que nous utiliserons juste en dessous.
